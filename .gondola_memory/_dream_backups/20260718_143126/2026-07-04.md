## [gotcha] _split_safe_unsafe_yield multi-char partial marker bug
confidence: 0.95
Using rfind('<') on a buffer like '<<YIE' returns index 1 (the last '<'), making remainder='<YIE' instead of '<<YIE'. Since '<<YIELD>>'.startswith('<YIE') is False, the partial marker leaks as visible text. Fix: rewrite with suffix-scan approach reusing _has_partial logic.
