## [gotcha] Auto-scroll must respect userScrolledAway flag
confidence: 0.95
In updateStreamingDOM, checking only pixel distance to bottom ignores state.userScrolledAway. Must check both conditions or auto-scroll fights user's manual scroll intent.
---

## [architecture] userScrolledAway flag management location
confidence: 0.9
state.userScrolledAway is managed in scroll.js - scrolling up sets true, scrolling back down near bottom sets false. Components should read this flag to respect user scroll intent.
