# Memory — 2026-07-20

## [gotcha] Backticks cause shell escaping issues
confidence: 0.9
Backtick characters (`) in JavaScript code are difficult to modify via shell commands because shells interpret backticks as command substitution. Python scripts in /tmp/ were used as a workaround.
---

## [pattern] Use /tmp Python scripts for complex edits
confidence: 0.8
When shell escaping becomes problematic (backticks, complex regex), creating Python scripts in /tmp and executing them is more reliable than inline shell commands.
