## [gotcha] SSE streaming DOM updates block main thread
confidence: 0.95
Calling parseMarkdown() + innerHTML on every SSE chunk causes increasingly expensive renders as the accumulated text grows, eventually freezing the browser and causing it to dump all buffered chunks at once.
---

## [pattern] Throttle streaming DOM updates with requestAnimationFrame
confidence: 0.95
Use rAF-based throttling for streaming DOM updates so rapid SSE chunks coalesce into a single DOM update per animation frame, preventing main thread blocking.
---

## [decision] Separate throttled vs immediate streaming render methods
confidence: 0.9
Use rAF-throttled updateStreamingDOM during active streaming, but call synchronous updateStreamingDOMImmediate for the final render after stream ends to avoid pending rAF racing with completion.
---
